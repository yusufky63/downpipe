01 — File types

Extensions separated by spaces or commas, such as zip pdf mp4. A download is captured when its file name ends with one of them; tar.gz works too.

    02 — Excluded sites

    One site per line. *.example.org also covers every subdomain. A download stays in the browser when it comes from one of these sites or starts on one of their pages. Ports and paths are ignored.

      03 — Minimum size

      0 turns this off. When the server does not say how big a file is, it goes to Downpipe.
