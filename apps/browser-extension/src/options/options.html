01 — File types

Extensions separated by spaces or commas, such as zip pdf mp4. A download is captured when its file name ends with one of them; tar.gz works too.

    02 — Excluded sites

    One site per line. *.example.org also covers every subdomain. A download stays in the browser when it comes from one of these sites or starts on one of their pages, and media they play is not listed. Ports and paths are ignored.

      03 — Minimum size

      0 turns this off. When the server does not say how big a file is, it goes to Downpipe.

        04 — Media on pages

        Used while Media on this page is on in the toolbar popup. HLS and DASH streams are always listed; the excluded sites above apply here too.

        Extensions separated by spaces or commas. A file without one is judged by the type the server sends. An empty list lists streams only.
